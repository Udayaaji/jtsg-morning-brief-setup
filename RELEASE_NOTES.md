JTSG Morning Brief installer 1.0.1.

Installs the Morning Brief pipeline under your user profile with a private
Python, Claude Code, and a Monday to Saturday 06:40 schedule with catch-up.
See docs/INSTALL_GUIDE.md for the steps, including the Windows SmartScreen
warning.

New in 1.0.1: an everyday guide is now installed on the computer and opens from
a new Start Menu shortcut, Help. It covers the morning routine, the files you
receive each day, how to read the status report, what each notification means,
and how to pause or retime the run. It works offline, so there is no need to
return to this page once the install is done.
